NovelAI 强调语法转换器

把 NovelAI 的 :: 段落权重、{} [] 位置权重转成 ComfyUI 的 (tag:weight)。三个开关按编号顺序依次作用，可以任意搭配。
① 解析 :: {} []，负权重自动分流到负面提示词 → ② 剥掉所有权重壳，只留裸 tag → ③ 负面串权重 ×(-1)（(blurry:1.4) → (blurry:-1.4)，裸 tag → (tag:-1)），正面不动。三个都不勾则原样输出。
输入时自动实时转换
已含从正面分流出的负权重 tag，直接贴进 CLIPTextEncode 的 negative 输入
输入含义输出
1.3::tag段落权重(tag:1.3)
{tag}加强，每层 +0.05(tag:1.05)
[tag]减弱，每层 −0.05(tag:0.95)
-1.4::tag负权重（NAI 写法）移出正面，负面槽位得 (tag:1.4)
(tag:-1)负权重（A1111 写法）同样按方向分流，负面槽位得 tag
权重恰为 1无强调不加括号，原样输出
(tag:1.3)步骤 ② 权重归 1tag，权重壳剥掉
负面 tag步骤 ③ Krea2 Prompt Weight节点(tag:-N)，按原强度取反((blurry:1.4)→(blurry:-1.4))；正面 tag 不变
